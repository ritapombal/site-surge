# SURGE — Webdesign · UC Planificação

Projeto final da Unidade Curricular de Webdesign.

## Estrutura do Repositório

```
site-surge/
│
├── 00-introducao/
│   └── exercicio-grupo/          # Exercício de grupo · Sessão 1 (21/2)
│
├── 01-investigacao/               # FASE 1 · Sessões 2–4 (2/3 → 16/3)
│   ├── analise-mercado/           # Desk Research + Benchmarking
│   ├── experiencia-digital/       # User Journey simplificado
│   └── relatorio-fase1/           # Relatório de Grupo Fase 1
│
├── 02-estruturacao/               # FASE 2 · Sessões 5–7 (23/3 → 13/4)
│   ├── arquitetura-informacao/    # Sitemaps + hierarquia de menus
│   ├── wireframes/                # Wireframes Low-Fi (papel/digital)
│   └── relatorio-fase2/           # Relatório de Grupo Fase 2
│
├── 03-design-visual/              # FASE 3 · Sessões 8–12 (20/4 → 18/5)
│   ├── figma/                     # Ficheiros Figma / exports
│   ├── mockups/                   # Mockups digitais
│   ├── prototipo-navegavel/       # Protótipo com hotspots e microinterações
│   └── relatorio-fase3/           # Relatório de Grupo Fase 3
│
├── 04-validacao/                  # FASE 4 · Sessões 13–15 (25/5 → 8/6)
│   ├── testes-usabilidade/        # Resultados de testes + ajustes
│   ├── comunicacao-visual/        # Poster A3 + deck de apresentação
│   └── relatorio-final/           # Relatório Final (Fases 1–4) + Poster impresso
│
├── relatorios-individuais/        # Mini-relatórios individuais (25%)
│   ├── mini-relatorio-1/          # Entrega Sessão 3 (9/3)
│   ├── mini-relatorio-2/          # Entrega Sessão 6 (30/3)
│   ├── mini-relatorio-3/          # Entrega Sessão 11 (11/5)
│   └── mini-relatorio-4/          # Entrega Sessão 14 (1/6)
│
├── autoavaliacao/                 # Auto e avaliação pelos pares (5%)
│
└── src/                           # Código-fonte do site
```
